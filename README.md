## CN2 GIA、CMI、AS9929：三条回国线各管一段路

优质洛杉矶机房常见的回国精品线路有三条。中国电信 CN2 GIA 速度快、丢包低、延迟稳定，是三条里最通用的一条；中国移动 CMI 对移动宽带用户更友好，成本也低一些；中国联通 AS9929 在中国东部和北部体验较好。旧金山、西雅图、凤凰城这些美西城市同样有 BGP 网络，但直连中国的线路资源有限，部分只走普通 IP transit 回国，稳定性和延迟都要差一截。

SixtyNet 的线路标签集中在 AS9929 上。AS9929 属于联通精品网，国内访问方向对北方和华东用户通常比普通国际出口稳。它的 China Unicom-Premium 方案除了 AS9929，还写明可以免费建立 BGP 会话、提供有限的 BGP 技术支持，基础带宽 100M、允许 3 倍突发、按 95 计费。这套参数面向的是自带 ASN 和 IP 段、要自己做广播的用户，不是给一台 VPS 装个网站用的。

线路好不好，别只看商家写的“CN2”“三网优化”，自己测三次就够。拿到 IP 后先 ping 一轮看延迟区间和丢包，再用 tracert 看第一跳落在哪个上游，最后找机房的 Looking Glass 从对端回测。同一座城市里线路差异有多大，轻树的价目表是个现成的例子：洛杉矶同一个城市下并存 CU4837、NTT、GTT、Cogent 四种上游，月付从 ¥54 到 ¥90 不等，还区分原生 IP 和住宅 IP。

真正需要盯的是北京时间晚 8 点到 11 点。中美网络在这个时段容易出现延迟飙升，走公共出口的机器尤其明显。测速放在下午做，数字会好看得多。

## 四个只写在条款里的限制

**住宅 IP 方案不开放 80 和 443 端口。** 官网在每一档 Residential 方案下都写明了原因：IP 风控。这意味着你不能用它直接跑面向公众的网站，访问必须经过配置，只有白名单或端口转发的设备能连入。想建公开站点，走 LAX 系列。这是最容易被忽略、也最容易买错的一条。

**部分方案的退款只进网站余额。** AS9929 优化系列的产品说明里明确写着退款仅对网站余额有效，不是退回原支付渠道。第三方整理还提到 SixtyNet 的退款窗口是 3 天，短于行业常见的 30 天。这两条叠在一起，意味着下单前的配置确认比事后反悔重要得多。

**China Unicom-Premium 的 100M 不是独享不限量。** 页面写的是 100M 基础网络、3 倍突发速率、95 计费。95 计费的意思是每月按流量峰值去掉最高 5% 后的值计费，突发能短暂冲到 300M，但持续跑满会体现在账单上。

**支付方式要提前确认。** 有第三方整理提到信用卡通道因风控暂停，下单前在结账页确认可用方式，别等到最后一步才发现付不了。

## 按场景对号入座

**跨境独立站。** 国内访问靠 CN2 GIA 提升速度，北美用户走本地优化网络，一套机房覆盖两个市场。配置下限建议 2 核 2G 起，LAX-STARTER 够起步，日活上来再升 LAX-MICRO。

**视频、直播转码、CDN 边缘。** 洛杉矶带宽资源密集，常被当作亚洲内容的第一跳。这类业务看的是出站带宽和存储 IO，LAX-LARGE 的 10G 端口加 40TB 流量是这条线里合适的档位，再往上就是 China Unicom-Premium 那种大带宽机器。

**游戏后端。** 对时延敏感，BGP 多线同时服务国内玩家和 Steam、PS 平台及北美用户。LAX 系列带 DDoS 防护这一点对游戏服是刚需，公开 IP 被扫被打的概率不低。

**远程开发环境和内网穿透跳板。** 借精品线路在国内快速访问海外工具链，1 核 1G 就够，轻树 ¥54 那档或 Cloudzy $2.48 那档都能干，没必要上 4 核。

**灾备第二区域。** 洛杉矶和芝加哥、Ashburn 之间的距离足够远，区域故障时只是一次切换。GigeNET 给出的点对点电路数据是洛杉矶到芝加哥约 40ms、到 Ashburn 约 52ms，做异步复制很宽裕。常见做法是芝加哥放主库、洛杉矶放副本。

**社媒多账号、SEO、采集。** 这类需求要的是住宅 IP，机房 IP 容易被平台标记。Residential 系列正是为此设计的，代价是 80/443 关闭，只适合程序化访问，不适合建站。

## 常见问题

**洛杉矶服务器比美东贵还是便宜？** 同配置下洛杉矶通常不便宜，因为海缆登陆点和回国线路资源都集中在这里，需求更密集。华纳云的说法是洛杉矶机房密度高、竞争激烈，价格相对合理。真正决定价格的是线路和带宽，跟东西岸关系没那么大。

**CN2 GIA 和普通 BGP 差多少？** 差距主要体现在晚高峰的稳定性和丢包率上，白天可能看不出来。判断方法是同一个时间段分别 ping 两条线路，比较晚 8 点到 11 点的延迟波动。

**美国服务器需要备案吗？** 机房在美国，不涉及国内 ICP 备案流程，买来即可部署。但如果域名要解析到境内 CDN 或境内接入商，备案要求按域名和接入方的规则走，跟服务器位置是两件事。

**月付还是年付？** SixtyNet 的年付标价省 17%，LAX-STARTER 从 $240 降到 $200。第一次用建议先确认配置对不对，尤其住宅 IP 那条端口限制；确认无误再切年付，17% 的折扣才拿得踏实。

**能装 Windows 吗？** 官网套餐页没有列操作系统清单。轻树那边支持 Windows 的档位比同配置 Linux 档每月贵约 ¥12，可以作为授权成本的参照。SixtyNet 的具体支持情况在下单页确认。
